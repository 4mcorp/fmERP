## 범위와 한계
- 대상: M2 변경 전체(packages/core 권한·조직 규칙, 마이그레이션 0003·0004, apps/web/server 라우트·org-access, 초대 프리셋). 직접 코드를 읽고 통합 테스트로 재현해 확인한 **자체 리뷰**이며, `differential-review` 스킬·Semgrep은 실행하지 않았다.

## 점검한 경로와 결과
| 경로 | 결과 | 근거 |
|---|---|---|
| 다른 계정 사업자·부서·직위·소속·역할 조회·수정 | 차단 | RLS + 복합 FK, 7개 신규 테이블 격리 테스트, 타 계정 id로 수정·이동·삭제 시 404 |
| API를 거치지 않은 직접 쓰기로 뎁스·순환·사업자 불일치 | 차단 | DB 트리거 통합 테스트 |
| 일반 구성원·감사인·인사 관리자의 부서 편집 | 403 | 통합 테스트 |
| 사업자 관리자의 범위 밖 부서·소속·초대 | 403 | 통합 테스트 |
| 사업자 관리자의 권한 상승(관리자 초대, 역할 부여, 소유자·관리자 비활성화) | 차단 | `role.grant` 계정 관리자 이상, 대상 역할 검사 |
| 소유자 동시 상호 비활성화 (M1 FU-3) | 해결 | 소유자 행 `FOR UPDATE` 잠금, 동시 요청 결과 200·409 |
| 발령 이력·감사 로그 변조 | 차단 | UPDATE·DELETE 권한 없음 |
| CSV 수식 주입 | 완화 | 내보내기에서 `= + - @` 시작 값 앞에 `'` 부여 |
| CSV 가져오기 남용 | 완화 | 500행·본문 크기 제한, 전부 성공 또는 전부 취소 |
