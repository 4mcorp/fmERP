## 목표
PRD의 **P0 요구사항 118개 전부**를 구현해 파일럿 고객 1곳이 실제 결재 업무를 운영할 수 있는 상태로 만든다.
완료 기준은 PRD 4장의 Phase 1 기준이다: 4주 무장애 운영 + 이관 리허설 성공.

## 범위
- **포함:** P0 요구사항 전체 (아래 마일스톤별 표). 감사 기능은 Must·Should 중 P0만 포함한다.
- **제외:** P1·P2 요구사항, PRD 10.3의 감사 Optional 기능, HWP 미리보기(D9)

- **소셜 로그인은 마지막(M9)에 구현한다.** M1~M8은 시드로 만든 테스트 계정으로 개발·테스트한다. 인증 엔진(Better Auth)과 세션·계정 구조는 M1에서 확정하므로, M9에서는 공급자 설정과 계정 연결 화면만 추가한다. AUTH-005는 ①새 계정·②초대 합류를 M1, ③도메인 자동 합류(Google Workspace 정보 필요)를 M9에서 구현한다.
- 기간은 1인 개발 + 에이전트 기준의 거친 추정입니다(합계 약 14주. PRD 4장의 Phase 0+1은 12주). 각 마일스톤 착수 시 상세 계획(plan)을 따로 작성하면서 다시 추정합니다.
- 결재 엔진(M3)은 DB와 무관한 순수 TS라 M1·M2와 병행하면 전체 기간을 약 2주 줄일 수 있습니다.
- 감사 단계(AUD-001)는 M3 엔진에서 결재선 단계 유형으로 먼저 지원하고, M6에서 설정 화면과 감사인 기능을 완성합니다.
